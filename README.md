# Tawhidul Bhuiyan Sabbir — Portfolio

A responsive personal portfolio built using the technologies required for the project:

- HTML
- CSS
- JavaScript
- JSON

## JSON usage

`data.json` stores the portfolio's skills and project information.  
`script.js` loads that JSON data and dynamically displays it on the website.

## Contact

## Run locally

Because JavaScript uses `fetch()` to read `data.json`, open the project using **Live Server** in VS Code rather than opening `index.html` directly.

## Before publishing

Replace the `#` placeholders for GitHub and LinkedIn with your real profile links.

## Deployment

The project can be pushed to GitHub and deployed with Vercel.
